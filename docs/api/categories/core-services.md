---
title: Core Services
---

**Core Services** are the building blocks of the Freepower API.

These endpoints are small, focused, and designed to do one thing well — like searching for addresses, validating metadata, or fetching raw plan details. They're ideal when you're building your own custom app flow or need fine-grained control over what happens.

Use Core Services when you want to:

- Build flexible or tailored user experiences
- Validate or enrich data before calling other endpoints
- Break down or chain logic in your own application

They don’t offer high-level decisions or recommendations — just clean, composable API primitives.
