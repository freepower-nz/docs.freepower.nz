---
title: Power Tools
---

**Power Tools** are Freepower’s estimation and calculation engines — built for precision, flexibility, and full control.

These endpoints usually handle large or detailed payloads. They’re ideal for advanced users who want to simulate usage patterns, model solar setups (coming soon), or calculate pricing with exact accuracy — whether you're using standard public plans or your own handcrafted ones.

Use Power Tools when you want to:

- Fine-tune household usage profiles and intervals
- Run pricing simulations on custom or unofficial plans
- Get deep insights into how specific changes affect costs

If Smart Actions are the shortcuts, Power Tools are the sandpit.
